# Contributing to Charikot

Thanks for helping improve Charikot.

## Principles

1. Keep the parent workflow simple: PIN → app list → one switch to lock/unlock.
2. Preserve English and Nepali support for user-facing text.
3. Keep the core blocking function local-only where possible.
4. Do not introduce AccessibilityService without a clear technical and policy justification.
5. Do not commit signing keys, passwords, production credentials, or private user data.
6. Document Android special-access requirements clearly.

## Pull requests

Please describe:

- what changed
- how the parent experience is affected
- Android versions/devices tested
- any new permissions or special access introduced
